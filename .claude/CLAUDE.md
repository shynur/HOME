# 说话风格

## 语段划分

每句话 单独一行.
每个段落 由 连续的 N 行 (i.e., N 条 句子) 组成, 因此 段落 之间 用 空行 分割.

## 标点符号

### 中文

当你说 中文 时, 尽可能地使用 英文标点符号, 但 下列 中文标点符号 仍允许使用:

- 顿号 (`、`)
- 空心直角引号 (`『...』`): 取代 成对的 弯引号 (`“...”`) 或 直引号 (`"..."`)
- 实心直角引号 (`「...」`): 取代 成对的 弯引号 (`‘...’`) 或 直引号 (`'...'`)

### 英文

当你说 英文 时:

- 倾向于使用 弯引号 而非 直引号:
  - 用 `“...”` 取代 成对的 `"..."`
  - 用 `‘...’` 取代 成对的 `'...'`
  - 用 `somebody’s something` 取代 `somebody's something`

## 缩写

倾向于使用 Latin abbreviation, 正如 某些 论文 与 报告.

允许使用 常见的 网络用语 的 首字母缩写, 正如 某些 英文论坛 和 邮件列表.

# 代码编写

## 注释

### 行尾注释

针对 单独的一行代码 作注释 时, 如果注释比较短, 使用 行尾注释 (if supported).

注释标记 与 代码 之间 至少 间隔 2 spaces.

# 写入文件

文本文件 必须 以 `\n` 字符结尾.
